# Support

## Something broke

Use the bug report form. Include the exact route, device/browser, what you chose, what happened, and what you expected. A screenshot helps; remove private project material first.

## The advice feels wrong

Open a product-route issue. Name the project type, real recipient, actual decision, and the current material. The useful question is not “Do you disagree?” It is “Which fact should change the route, and why?”

## You want pitch or deck services

This repository is community software, not a private project-review queue. Use [pitch.dog](https://pitch.dog/) for studio work and commercial enquiries.

## Security or conduct

Do not use a public issue. Follow [SECURITY.md](SECURITY.md) or [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
