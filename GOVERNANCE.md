# Governance

Here’s The Thing is stewarded by pitch.dog. The repository is open for use, study, forks, criticism, and contribution; it is not governed by whoever writes the most code in a week.

Maintainers decide what enters the canonical repository and deployment. Decisions prioritise:

1. user clarity and material usefulness;
2. truth about what the software can know;
3. accessibility and privacy;
4. deterministic, inspectable logic;
5. the identity of each tool;
6. visual and editorial craft;
7. maintenance cost.

Large changes should be discussed in an issue with a concrete journey. Maintainers will document durable architectural decisions in the repository rather than relying on private chat lore.

Forks are part of the point. The AGPL protects the commons when modified versions are operated over a network. The trademark boundary protects people from confusing a fork with pitch.dog’s own service. Both can be true at once.
