# Names, marks, and forks

The source is open. Brand identity is not ownerless.

`pitch.dog`, the pitch.dog logo, and the official Here’s The Thing presentation are identifiers of the original project. The software licences do not grant permission to claim endorsement, impersonate the official service, or use the marks as the primary identity of a modified version.

You may:

- state truthfully that your fork is based on Here’s The Thing;
- link to this repository and name pitch.dog for attribution;
- show the official interface or mark when reviewing, teaching, or documenting the project in a way permitted by applicable law.

If you distribute or host a modified version, give it a distinct name and visual identity. A clear footer such as “Forked from Here’s The Thing by pitch.dog; not affiliated with pitch.dog” is useful.

The approved logo duplicate remains in the repository because the official build needs it and the project should be reproducible. Do not treat that file as a general-purpose logo pack.
